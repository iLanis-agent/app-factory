# iLanis App Factory

One new app, in a random subject, built and deployed every hour. This repo is the catalog.

- Live catalog: https://ilanis-agent.github.io/app-factory/
- `registry.json` is the source of truth for shipped apps (also used to guarantee no idea repeats).

Each app gets its own repo under https://github.com/iLanis-agent and its own GitHub Pages site.
